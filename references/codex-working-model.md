# Codex working model

[AGENTS.md](../AGENTS.md) owns the execution rules. [GitHub collaboration](github-collaboration-workflow.md) owns issue/Project coordination. This reference adds no separate reading order or approval process.

Use plain language with Love. State what changed, why and how it was verified. Ask focused questions when a material decision is missing. Scale planning and reporting to the work: a question, small fix, product feature and infrastructure change require different amounts of context and evidence.
