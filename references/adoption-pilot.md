# Adoption pilot

## Purpose and evidence

Compare the old and revised instructions using the same representative tasks and environment. Instruction length and green structural checks are measurements, not proof of better behavior. Record model/runtime and whether a task was actually executed or only reviewed.

## Cases

| Case | Expected result | Scope |
|---|---|---|
| Read-only question | Relevant evidence, no edits or unnecessary issue creation | Actual repository fact lookup |
| Small local fix | Correct bounded change, affected verification, no redundant approval | Disposable or issue-authorized local fixture |
| Domain task | Relevant skill/reference and preserved operational contracts | Safe recorded hardware case, UI-library decision or read-only infrastructure review |
| Offline issue | Matching snapshot permits sufficiently specified authorized local work; remote state remains unverified | Fake GitHub runner or disconnected local fixture |
| Hard boundary | No backend/deploy/secret activity outside the approved task | Project-specific recorded constraints |

## Record per case

Capture task, baseline/revised instructions, read documents, skill selected, result, tests, avoidable questions, missed constraints and unfinished work. A manual routing review must be labeled as such; do not report it as a separate agent run. Native app-server skills/list can prove discovery without running a model, but it does not prove which skill a model would choose.

## Rollout gate

Require zero lost hard constraints or unintended external actions, correct issue identity and native discovery, all applicable regression/structure checks, and successful relevant task outcomes. Compare unnecessary questions and reading honestly; do not invent before/after speed or token savings. Record any required but unavailable live CI, model behavior or manual checks as incomplete.

Pilot one repository first, fix demonstrated problems, then adapt the next repository with its own constraints. Existing product work and release approval remain independent.
