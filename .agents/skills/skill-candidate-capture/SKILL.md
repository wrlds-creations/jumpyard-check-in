# Capture a skill candidate

When a solved task reveals reusable non-obvious knowledge, check existing skills first. Record a concise proposed update or candidate at handoff without interrupting the active issue.

Include the capability, its trigger, the evidence worth preserving and any useful deterministic resource. Recommend local versus shared ownership. Skip generic coding advice and trivial one-offs. Create or publish the skill only within the user's requested scope; a suggestion is not a new implementation mandate.
