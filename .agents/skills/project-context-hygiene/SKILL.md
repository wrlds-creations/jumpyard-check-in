# Project context hygiene

Preserve current facts, constraints and useful evidence while making active memory easier to use. A small routine factual update does not require a repository-wide cleanup.

Before restructuring, inspect the affected documents and their incoming references. Identify confirmed facts, live constraints, historical evidence, duplicates and unresolved gates. Use existing validation to record the starting state for a substantial rewrite.

Keep issue scope and Project fields in GitHub; retain durable facts/decisions in their owning repo documents. Archive useful history under docs/history before removing it from active context. Keep historical IDs and provenance searchable. Preserve exact user-facing copy, business terminology and quoted evidence; durable summaries are English by default.

Verify affected links and structural checks after moving content, and review that no live constraint or unresolved gate disappeared. Do not alter product behavior, cloud resources or credentials during memory cleanup. Capture unrelated findings within the already authorized coordination channel or local pending notes.

Archive historical instruction files under non-triggering names such as AGENTS.before-workflow-0.2.md; an archived AGENTS.md can still act as nested instructions.
