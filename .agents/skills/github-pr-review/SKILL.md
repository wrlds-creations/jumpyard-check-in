# Address PR feedback

Read the relevant review comments and current diff. Implement actionable changes within the user's approved scope, preserving the intended behavior and reviewers' substantive concerns. Previously authorized architecture changes do not need approval again; ask only for a new material decision or scope expansion.

Run relevant verification and report which findings are addressed and which remain. Do not automatically post replies, resolve threads, request reviewers or merge unless those external actions are authorized.
